# reipedia-reports

Reipedia (https://rei-aios.org/reipedia/) の 誤り を 報告 する ための 公開 窓口 です。

## 目的

Reipedia の 項目 の 誤り を 読者 から 受け取ります。 Reipedia 本体 の ソース リポジトリ は 非公開 の ため、 誤り 報告 は 本 リポジトリ の issue で 受け付けます。

## 報告 の 方法

[「誤り 報告」 の issue を 新規 作成](https://github.com/fc0web/reipedia-reports/issues/new?template=error-report.md) して ください。 テンプレート の 項目:

- 項目 の ID か URL
- どこ が 誤り か
- 根拠 や 出典

## 報告 の 扱い

いただいた 報告 は、 Reipedia の [訂正記録](https://rei-aios.org/reipedia/corrections/) の 手順 に 従って 扱います。 返信 や 反映 の 時期 は お約束 できません。 いただいた 報告 は 確認 した うえ で、 正しい と 確かめ られた もの から 訂正記録 に 反映 します。

## ライセンス (Reipedia 本文)

Reipedia 本文 (項目 の 説明文) は [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) で 公開 して います。
